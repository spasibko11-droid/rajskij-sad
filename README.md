# Райский сад

Одностраничный сайт пространства заботы и творчества «Райский сад» (г. Голицыно).

Чистые HTML, CSS и JavaScript без сборки: `index.html`, `styles.css`, `script.js`.

## Как посмотреть локально

```
python3 -m http.server 8080
```

и открыть http://localhost:8080/

## Где что лежит

- `images/garden/` — слои сада для главного экрана (фон, кусты, ветки)
- `images/about/`, `images/rent/`, `images/gallery/` — фото блоков
- `images/icons/` — акварельные иконки направлений
- `images/deco/` — декоративные ветки по краям
- `assets/` — логотип и иконка вкладки

Формы заявки пока не отправляют данные, их нужно подключить к почте или Telegram (см. `TODO` в `script.js`).
